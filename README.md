# TStorage 🗂️

TStorage is a simple and lightweight **temporary file storing and sharing platform**. Users can upload files and get a shareable download link, which expires after a limited time. Ideal for quick file transfers without signups or cloud clutter.

### 🌐 Live Demo
▶️ [tstorage-1.onrender.com](https://tstorage-1.onrender.com)

---

## 🚀 Features

- 🔼 Upload files quickly via browser
- 🔗 Get a shareable download link instantly
- 🕒 Files stored temporarily (auto-deleted after a period)
- 💡 No authentication required
- 🔒 Safe and secure transfers (supports large files)

## 🔧 Setup Instructions

1. **Clone the repository**
```bash
git clone https://github.com/kunalmaurya-17-24/TStorage.git
cd TStorage
````

2. **Install dependencies**

```bash
npm install
```

3. **Run the server**

```bash
node backend/index.js
```

4. **Access the frontend**

* Open `frontend/index.html` in your browser
* Or configure Express to serve static frontend files
